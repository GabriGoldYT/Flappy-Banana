# 🍌 Flappy Banana

Um jogo simples e divertido inspirado no clássico Flappy Bird, mas com uma banana no lugar do pássaro e facas como obstáculos!

## 💡 Sobre o projeto

A ideia surgiu quando pensei em criar uma versão diferente de Flappy Bird, usando uma banana em pixel art como personagem principal. A partir disso, desenvolvi o Flappy Banana, um jogo em que o objetivo é desviar das facas e conseguir a maior pontuação possível.

Usei essa ideia para criar meu primeiro projeto no GitHub e começar a colocar em prática meus estudos de programação. Sou estudante de Análise e Desenvolvimento de Sistemas e pretendo continuar aprendendo, desenvolvendo jogos e compartilhando minha evolução por aqui.

## 🎮 Como jogar

* Clique, toque na tela ou aperte Espaço para fazer a banana pular.
* A cada pulo, a banana também gira.
* Desvie das facas sem encostar nelas.
* Passe pelos obstáculos para ganhar pontos.
* Tente superar seu próprio recorde!

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Canvas API

## 🚀 Como executar

Basta baixar o arquivo `flappy_banana.html` e abri-lo em um navegador. Não é necessário instalar nada.
